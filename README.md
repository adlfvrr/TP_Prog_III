## 🎓Trabajo Práctico Programación III

---

En este repositorio estaré trabajando con un trabajo práctico académico para la cátedra de Programación III. <br>
📝En el mismo se dará el desarrollo de una aplicación web que sea capaz de:
- CRUD para crear o actualizar datos de la facultad
- CRUD para el manejo de proveedores (Terceros)
- CRUD para el manejo de facturas, manejando relaciones foráneas con sus items y vinculos con terceros
- CRUD para el manejo de pagos, manejando relaciones foráneas con terceros y detalles de pago

❗ Se trabajará con una estructura y datos de base de datos dados por el profesor.

## Stack solicitado para el Trabajo práctico:
📚En el trabajo se solicita las siguientes tecnologías:
- Java como lenguaje Backend, Spring como framework.
- Vaadin Flow/Hilla como Frontend (+25)
- PostrgreSQL como motor de BDD (gestión con DBeaver)
- Autenticación con tokens (en mi caso utilizaré JWT)
